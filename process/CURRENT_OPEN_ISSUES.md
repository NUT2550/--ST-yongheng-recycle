# Current Open Issues — YH Stock System

> **Deprecated as a live task list.**
> Last reconciled: 2026-08-07

## Why this file changed

This file previously duplicated issue state, priorities, and old implementation notes that are now maintained elsewhere. Keeping a second “current issues” list in the repository caused stale status and conflicting next steps.

## Canonical current sources

Use:

- **Linear** — live task state, priority, blocker, acceptance criteria, next gate
- **GitHub Issues/PRs** — technical issue detail, branches, PRs, review/CI evidence
- **`process/CURRENT_STATE.md`** — concise current technical snapshot and verified/unverified state
- **Notion** — durable Owner/business context and decisions, not duplicate issue tracking

## Rules

- Do not add live issue status or priority updates to this file.
- Do not use historical entries from prior revisions as current truth.
- If a task is missing from Linear/GitHub, create/update it there according to the project workflow rather than recreating a list here.
- Current technical state must be re-verified from current sources before action.

## Historical record

The previous detailed issue list is preserved in Git history and may be used for audit/history only.

## Key takeaway

**This file is no longer a task tracker. Use Linear + GitHub for current work and `CURRENT_STATE.md` for the concise technical snapshot.**
